# Reports

This directory contains product evidence used by release validation.

- `*-live-verification.json` records controlled execution evidence for executable modules or templates.
- `public-case-*.json` records representative public-data validation cases.
- `*-verification.json`, `tool-compatibility-matrix.json`, and `format-contract-registry.json` bind the plugin contract, registry, compatibility rows, and release checks to the current source tree.

The reports are evidence artifacts, not user instructions. Private development records, one-off local maintenance records, credentials, and machine-local paths are not part of the public product.
