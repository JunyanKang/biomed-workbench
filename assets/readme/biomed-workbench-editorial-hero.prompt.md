# Biomed Workbench README hero prompts

## Purpose

Create a bilingual pair of restrained README illustrations. Both versions use the same composition; only the five stage labels change language. The visual explains one research path rather than listing every workbench capability.

## Base illustration

Create a publication-grade biomedical editorial illustration in a wide 2:1 landscape composition. Use a warm off-white background, dark navy linework, muted teal and restrained coral accents. Keep at least one quarter of the canvas empty and reserve a clear label band above the content.

Show exactly five left-to-right stages linked by one thin continuous path:

1. **Study design:** one biological specimen, two paired sample-group tubes and a magnifying lens focused on the comparison.
2. **Multi-scale data:** four non-overlapping representations—a bulk sequencing track, a single-cell cluster map, a spatial tissue grid and one folded protein structure.
3. **Analysis:** three ordered analytical layers for quality and design checks, primary analysis and cross-data integration. Do not repeat the biological icons from the previous stage.
4. **Interpretation:** one publication-style scientific figure page beside one concise report page.
5. **Research delivery:** one compact portfolio containing a scientific figure sheet, a manuscript page and a next-step research-plan page. A subtle return path toward the first stage shows that delivered interpretation can inform future research; it must not imply that the workbench performs a wet-lab experiment.

Every object must explain one of these stages. Keep equal visual weight across the composition, consistent baselines and no more than twelve significant objects. Exclude decoration, repeated filler icons, floating molecules, ornamental equipment, fake quantitative values, dashboards, robots, servers, logos, watermarks and pseudo-text.

## Chinese label pass

Preserve the base illustration exactly. Add five equal-size, dark navy, medium-weight Simplified Chinese labels on one baseline, centred above the corresponding stages:

`研究设计` · `多尺度数据` · `方法分析` · `结果解释` · `科研交付`

Add no other text, numbering or punctuation.

## English label pass

`Study design` · `Multi-scale data` · `Analysis` · `Interpretation` · `Research delivery`

Add no other text, numbering or punctuation.
