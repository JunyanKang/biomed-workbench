# GWAS Fine-Mapping

`gwas-susie-fine-mapping` prepares a strict SuSiE-RSS analysis for one independently selected locus. It requires pre-harmonized summary statistics and a same-order, ancestry-compatible LD correlation matrix. The template validates effect alleles, numerical statistics, LD symmetry, unit diagonal, positive semidefiniteness, source SHA-256 digests, frozen maximum-effect and credible-set coverage settings, package versions, convergence, and reloadable posterior output.

The output provides model- and LD-reference-dependent PIPs and credible sets. It is not evidence of a causal variant, causal gene, colocalization, molecular mechanism, clinical actionability, or functional validation. Variant selection, allele harmonization, LD generation, ancestry assessment, locus selection, sensitivity analysis, colocalization and experimental follow-up remain explicit linked steps.
