# 国家自然科学基金申请书研究与写作

语言：[中文](nsfc-proposal-writing.zh-CN.md) · [English](nsfc-proposal-writing.md)

Biomed Workbench 按申请年度和项目类型组织国家自然科学基金申请材料。目前内置 2026 年配置，分别覆盖青年科学基金项目 C 类、B 类和 A 类，以及面上、地区、重点和重大项目。不同项目使用独立配置，不会把美国国家科学基金会的评审条款套用到国家自然科学基金申请书，也不会用青年项目模板替代重点或重大项目提纲。

## 七类项目怎样区分

| 项目类型 | 论证重心 | 2026 年正文与篇幅处理 |
| --- | --- | --- |
| 青年 C | 独立提出科学问题，目标集中，研究规模与前期基础相称 | 官方已明确正文由立项依据、研究内容和研究基础三部分组成，原则上不超过 30 页 |
| 青年 B（原优青） | 代表性学术贡献、持续研究主线、未来研究的跃迁性及团队和条件支撑 | 从科学基金网络信息系统下载当年该项目模板；没有绑定模板时不采用经验字数 |
| 青年 A（原杰青） | 原创且持续的学术贡献、国际前沿位置、申请人个人贡献和未来引领性 | 从科学基金网络信息系统下载当年该项目模板；没有绑定模板时不采用经验字数 |
| 面上 | 研究价值、课题自身逻辑、创新性与可行性的平衡 | 官方已明确正文由立项依据、研究内容和研究基础三部分组成，原则上不超过 30 页 |
| 地区 | 科学问题的创新价值、与地区研究条件相匹配的可行性及人才培养 | 从科学基金网络信息系统下载当年该项目模板；地域意义不能替代科学问题本身 |
| 重点 | 有限目标、已有较好基础、系统性与突破性，以及必要的学科交叉 | 从科学基金网络信息系统下载当年该项目模板，按指南领域和项目要求核对 |
| 重大 | 重大科学问题的统一定义、项目与课题分解、课题间有机联系和综合集成 | 必须同时绑定当年具体立项领域指南和项目模板；一个项目设置的课题不超过 5 个 |

面上、青年 C 和重点项目在 2026 年按申请人选择的研究属性开展分类评审。所有适用项目从“自由探索类基础研究”和“目标导向类基础研究”中选择一类。生命科学部的面上、青年 C 和地区项目，申请代码 1 必须选到二级代码。

## 从官方模板开始

每次申请先从[科学基金网络信息系统](https://grants.nsfc.gov.cn/)下载当前年度、当前项目类型的最新版申请书。工作台记录模板年度、项目类型、下载时间和文件校验值，再读取正文标题、表单字段和篇幅限制。模板不匹配、来源不明或沿用旧年度文件时，申请书不会进入定稿检查。

公开网页没有给出稳定数值的字段，不会被填入推测的字数上限。此类限制在提交前以官方在线表单和当前模板为准。面上和青年 C 的三部分结构及 30 页要求来自基金委 2026 年申请书改版说明，可直接检查。

## 怎样把研究材料写成申请书

工作台支持从研究构想到成稿、基于已有草稿修改，以及边补材料边重构三种方式。用户提供的历史申请书可以帮助识别作者惯用的论证节奏、段落密度、图文关系和术语偏好，但只提炼通用写作规律，不复制原项目的文本、数据、图像或未公开内容。

开始写作前，先整理已经确认的研究事实、前期结果、文献依据、候选解释和不能使用的强结论，再形成中心科学问题、中心假说、替代解释和预期知识增量。证据不按材料提供顺序或方法名称堆叠，而是根据前后依赖和它在论证中的作用重新排序：哪些建立领域认识与空白，哪些构成主要发现，哪些只能提供机制一致性，哪些是正交验证，哪些阴性结果限定结论。准备充分后，必须继续撰写或修改实际正文，不能以检查表、问题清单或内部写作方案代替申请书文本。

## 中英文摘要与全文语言修订

中英文摘要和全文语言修订是申请书交付的必要组成，不放在最后作为可选润色。摘要在正文科学逻辑稳定后完成，先写中文，再根据同一组科学概念形成英文版本。

中文摘要一般控制在 400 字以内，标点计入字数。当前项目类型的在线表单或当年模板若给出更具体的限制，以该限制为准。摘要不是立项依据的缩写，也不是方法清单，建议按照以下顺序压缩为一个连续段落：

1. 用一至两句界定研究对象、必要背景和仍未解决的科学问题；
2. 紧接中心科学问题或可检验假说，说明申请人的真实前期结果为何构成研究入口；
3. 概括相互衔接的研究目标、关键判别方法和能够区分替代解释的读出；
4. 以项目将带来的具体知识增量收束，不用宏观价值、口号或“首次采用某技术”替代科学贡献。

英文摘要以中文摘要为科学基准，不单独设置字数限制，也不是逐词翻译。它必须与中文摘要逐项对应研究对象、核心表型、中心机制、科学问题、中心假说、研究目标和预期知识增量，并保持相同的证据强度与不确定性。英文不得扩大因果表述、删去中文中的限制条件，也不得增加正文未出现的新主张。

正文完成后，从题目开始逐段复读至图题、表题和参考文献。工程开发、审计管理、软件编排和计算机系统视角的措辞，例如“执行器”“注册表”“状态机”“工作流编排”“输入输出契约”“机器可读”“渲染器”“校验值”等，必须改写为生命科学同行能够直接理解的问题、证据、方法、比较和结论。真实需要的生物信息学方法名、软件名、参数、数据结构和定量结果应准确保留，不能为了语言自然而删除方法学信息。修改后再次通读，核对段落承接、术语首次定义、物种和基因蛋白命名、机制动词、证据边界以及中英文摘要的一致性；仍有内部流程语言时，申请书不能进入最终交付。

## 文献和公共数据库怎样进入论证

项目书的文献工作不是在正文写完后补参考文献。首先围绕研究对象、关键过程、直接证据、相反解释和未解决问题设计检索式，并使用两个或以上适当来源核对覆盖范围。用于界定领域共识、直接支持、冲突证据或研究空白的核心论文，需要核对题名、作者、期刊、年份和 DOI，并阅读原文相应结果、图表与方法；摘要或数据库题录不足以支持机制性表述。

文献检索依次完成来源覆盖、去重、原文精读、引用身份核验和主张—证据复核。每条证据明确属于支持、削弱、反驳、背景或尚不能判断，冲突结果不会因不利于中心假说而被删去。研究空白必须说明检索覆盖了什么、已有研究为何仍不能回答当前问题，以及本项目将用什么判别性观察缩小这个缺口。

公共数据库只按课题需要调用。例如基因与同源关系可使用 NCBI Gene、Ensembl 或 UniProt；人类表型和变异可使用 HPO、ClinVar、gnomAD 或 Open Targets；通路可使用 Reactome 和 QuickGO；蛋白互作、结构、肿瘤队列、表达图谱和临床试验分别调用相应来源。每条数据库证据保留记录编号、数据库版本或更新时间、访问日期及其与正文主张的关系。数据库关联可以帮助说明人类疾病背景、候选优先级或研究意义，但不能自动证明拟议分子机制。

正文完成后再次检查：外部事实是否都有经过审阅的来源，当前项目结果是否连接真实实验或分析文件，引用编号与参考文献是否双向对应，来源是否仍适用于当前年度。上述步骤是写作过程的一部分，不以单独审计报告代替正文。

正文按以下次序组织：

1. 先写研究内容，明确每个目标要检验的假说、关键对照、判别性读出，以及不同结果分别支持什么解释；
2. 再写研究基础，使用申请团队的真实结果证明研究入口、关键材料和技术可行性，同时说明这些结果尚不能回答什么；
3. 据此完成立项依据，把领域共识、直接证据、冲突或缺口、科学意义、中心问题和项目入口连成连续论证；
4. 最后凝练题目、中英文摘要、创新性和年度计划，确保它们与正文使用同一科学问题和证据强度。

写作和修改过程中持续检查：

- 立项依据是否说明为什么开展研究及其科学价值，而不是提前堆入实验操作；
- 研究内容是否围绕同一问题展开，并说明每项结果将改变哪一项现有认识；
- 研究基础是否包含申请团队的真实前期数据和可行性依据，而不是文献综述；
- 每个研究目标是否连接核心表型或中心机制，是否有判别性观测指标、可替代解释、可行性证据和失败后的替代方案；
- 新概念是否在必要的前置概念之后引入，相邻段落是否保持问题承接，标题承诺是否由正文回答；
- 中文摘要和英文摘要是否保留同一组核心概念，摘要中是否混入编号式引文。

完整正文稳定后，必须使用项目书模式的学术表达修订能力。第一次检查定位模板化开场、空泛意义、无依据的优先性、引用堆砌、过长句和超过证据强度的动词，同时筛出偏向软件工程、系统流程、审计记录或计算机架构、却没有表达具体生物学关系的文字；随后将其改写为生命科学研究中的对象、过程、因果层级、实验观察和可证伪预测；最后把原稿与修订稿逐项比较。数字、结果、引用、专业术语、机制边界和有证据依据的不确定性不得改变，分析方法中确实必要的软件与参数也会保留。项目书不能被机械改成论文式克制语气：只要真实前期结果、既往工作、可行方法或风险控制能够支撑，中心愿景和预期贡献应保持清楚有力。写后复核未通过时，文本不能作为最终版本交付；通过后还要生成并重新打开带目录、证据文件和文献链接的 HTML 写作报告。

分析方法本身不能成为研究目标。增加一种组学、模型或算法时，需要说明它替代什么、能区分什么解释，以及是否改变下一项科学决策。

## 青年 C、青年 B 与面上的写作和图形侧重

青年 C、青年 B 和面上项目不会共用同一套叙事骨架。

- 青年 C 围绕一个边界明确、能够独立完成的科学问题展开。立项依据应快速收束到中心问题，研究方案通常由少数递进目标构成，前期结果用于证明研究入口和关键技术可行。图形应紧凑地连接问题、机制检验和生理意义，避免扩展为多条平行主线。
- 青年 B 先说明少数代表性贡献、申请人的直接作用及其共同形成的持续研究主线，再由这些贡献推出下一阶段的前沿问题和研究跃迁。成果总览图与拟开展工作图承担不同任务，已完成贡献和未来假说必须清楚分区，不能把论文数量或期刊名称当作学术贡献。
- 面上项目从领域共识与冲突证据形成科学张力，提出中心假说，再用相互依赖的研究内容、判别性实验和充分前期基础证明创新性与可行性。立项依据图、研究设想图、技术路线图和前期结果图各有独立功能，不合并为一张方法总览。

## 项目书插图

插图先确定它在上下文中的作用，再决定是否绘制。每幅图都要记录前文已经建立的主张、图后要引出的科学问题、允许读者得到的结论，以及不能由视觉元素暗示的关系。工作台分别处理六类图：立项依据的证据综合图、科学假说图、研究方案图、技术路线图、前期基础图，以及青年 B、青年 A 常用的学术贡献主线图。

立项依据图以经过核验和原文审阅的文献为基础，压缩已有认识、相互矛盾的解释、知识缺口和研究入口。科学假说图把已有证据、申请人前期结果、生物学推断、待检验假说、替代解释和能够否定假说的观察分别表示。研究方案与技术路线图展示模型、实验层级、关键对照、定量读出、结果分支、阶段目标和替代方案。前期基础图以真实显微图、印迹、测序结果或统计图为主体，生成式图像不能替代实验数据。

图形的主体由与课题直接相关的组织结构、细胞状态、亚细胞定位、分子复合体、模型动物、实验系统和真实数据构成，至少呈现两个必要尺度。文字只用于短标签、图例、引用和结论边界；单纯把段落拆成方框再连接，不构成合格的科学插图。

概念图先生成无文字或少文字的科学视觉参考和可分离生物学元素，随后把准确标签、引用、连接关系、图例与数据 panel 重建为可编辑对象。定量图使用统一论文绘图器或分析专属绘图器，显微图和印迹保持来源文件。最终交付包含可编辑 PPTX、PDF 和高分辨率 PNG。

每轮都在申请书最终插入尺寸下检查。字体家族控制在一至两种，同级文字使用同一字号，字号层级和文字颜色保持克制；文字、图例和数据层位于背景、生物学元素及连接线之上。具有逻辑对应关系的文字或图形保持水平或垂直对位，文字不得遮挡图形、越出容器或被底层元素覆盖；除有明确理由的特殊场景外，关键科学元素必须具备简洁标识。每个元素还要反向说明其科学作用和叙事权重，重复装饰与无信息元素必须删除，并按画面区域检查信息密度和留白是否均衡。插入 Word 时，图宽不得超过正文版心，图件单独占用显式居中的段落，段落中不得在图片前保留空格、制表符、空运行或缩进占位。校对同时覆盖生物学对象、箭头语义、证据颜色、文献归属、图题一致性和 A4 页面适配。发现科学含义或排版问题后只针对问题修改并重新渲染，直到两类问题均清零。

## 机制结论与术语

候选分子、底物和因果机制使用同一套结论升级条件。共表达或空间共定位不足以把候选分子写成底物；底物结论至少需要直接互作、位点特异修饰和催化依赖证据；进一步写成机制或因果关系，还需要连接表型，并在相应层级提供功能验证或挽救证据。这一限制同时适用于题目、摘要、中心假设、研究目标和预期结果。

术语检查使用项目自己的命名表，核对首次定义、缩写、物种、基因与蛋白、中文名和英文名。生物化学关系中的连接号，例如“玻璃体—视网膜界面”，不会被机械地判为语言问题；内部开发用语不会直接进入对外申请书。

## Word 申请书交付

Word 检查直接读取 `.docx` 文件，核对摘要、正文、参考文献、字体、字号、颜色、图题表题和嵌入图件。样式要求从当前官方申请书读取，不使用经验格式替代。编号引文按首次出现顺序检查，统一逗号、空格和范围连接号，正文引文与文后条目双向对应，并生成明确的重编号映射。引文标记没有跨 Word 文本片段拆开、文献条目完整且编号唯一时，可以生成单独的自动重编号 Word 副本；原文件不会被静默覆盖，副本必须再次检查。

最终版本还要逐页渲染。每页检查断页、遮挡、文字和图件的最终尺寸可读性，以及图题是否与图件保持在同一页。只有结构检查和逐页视觉复核都完成，才进入提交交付状态。

## 不同项目类型怎样改变写法

青年 C 强调独立提出并完成一个边界清楚的问题；青年 B 需要把代表性贡献、持续研究主线和下一步跃迁写成一个整体；青年 A 更重视持续原创贡献、前沿位置和未来引领方向；面上项目强调科学问题、研究内容与可行性的均衡；地区项目同时说明科学价值与现有研究基础；重点项目需要有限目标、较强前期基础和可实现的突破；重大项目则必须围绕同一个重大科学问题说明课题分解、相互依赖和最终集成。工作台据此改变论证重心和章节任务，而不是只替换项目名称。
