# Accelerated Stability

The accelerated-stability module compares zero- and first-order potency-loss fits at each supplied temperature. It makes an Arrhenius target-temperature prediction only when the same kinetic model is supported across all temperature groups.

Inputs must retain assay specificity, storage conditions, container closure, sampling schedule, temperature control, batch and replicate structure, and the declared acceptance specification. The result is model-bound extrapolation, not a validated shelf-life, release, expiry, or storage decision.
