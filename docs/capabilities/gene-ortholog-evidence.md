# Gene Ortholog Evidence

`gene-ortholog-evidence` retrieves NCBI Datasets Gene API records for one
stable source NCBI Gene ID and one declared target taxon. It preserves source
and target Gene IDs, symbols, taxonomic identities, returned Ensembl IDs,
unmapped results, response bounds, and request provenance.

Database orthology is a mapping resource, not proof of functional, expression,
regulatory, phenotype, cell-state, or experimental equivalence. Cross-species
analysis must retain the mapping release and independently review the intended
feature conversion.
