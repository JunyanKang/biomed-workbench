# 科学解释、研究叙事与结果决策

语言：[中文](scientific-interpretation-and-storytelling.zh-CN.md) · [English](scientific-interpretation-and-storytelling.md)

Biomed Workbench 把数据分析放在一条连续的研究主线上：科学问题决定分析，真实结果修正解释，经过复核的证据再决定下一项分析、实验或写作任务。它不会把方法清单当成研究方案，也不会把计算成功当成科学结论。

## 从问题到决定

| 阶段 | 工作台处理什么 | 用户首先看到什么 |
| --- | --- | --- |
| 理解问题 | 研究对象、实验单位、比较、对照、时间与空间背景、核心假说和竞争性解释 | 当前真正需要回答的问题 |
| 选择分析 | 分开识别实验方法、测量靶标、对照、归一化和生物学关系；每个问题优先采用一个主分析和一个必要的正交验证 | 为什么选择这些方法，以及它们分别能改变什么判断 |
| 执行与复核 | 使用实际项目输入运行流程，重新打开结果，核对效应大小、不确定性、样本层级、质量指标和阴性结果 | 主要观察及其可靠范围 |
| 生物学解释 | 把观察、计算、推断和假说分开；结合物种、组织、发育阶段、疾病状态与细胞区室检查解释 | 证据支持到哪里，还有哪些合理解释 |
| 研究决策 | 保留、限制、重做、替换或停止一个分析分支，并提出能够区分竞争性解释的下一项观察 | 下一步做什么，以及为什么 |
| 图表与写作 | 为每个图面确定科学任务，把结论连接到作图数据、图件、图注、正文和引用 | 一条有递进关系的研究故事，而不是分析结果堆叠 |

## 最小充分分析

默认情况下，一个科学问题只批准一个直接回答问题的主分析，以及一个假设、数据层或误差结构不同的验证。新增方法必须说明它替代哪项现有分析，或它能提供哪项现有结果无法提供的决策信息。

这一原则不会排斥必要的敏感性分析。参数依赖、算法依赖和替代模型仍可保留，但它们会被明确标记为敏感性结果，不会与独立证据混为一谈。

## 解释怎样自我修正

每个主要结论先形成一份紧凑的观察摘要，包括实验单位、方向、效应量或无法估计的原因、不确定性、独立重复数和当前状态。随后逐项检查：

- 结论是否超过实验设计和测量本身能够支持的范围；
- 技术质量、批次、样本组成或分析假设能否产生另一种解释；
- 阴性结果、互相矛盾的证据或缺失数据是否改变结论；
- 当前证据是相关、预测、空间邻近、候选机制还是直接功能证据；
- 哪一项新观察或实验最能区分领先解释与替代解释。

发现问题后，工作台会修改解释、缩小主张、采用已登记的替代方法、补充证据或排除结果，而不是只在报告末尾追加一份问题清单。

## 领域背景怎样参与判断

项目可以登记带版本的物种、组织、发育时期、疾病状态、细胞类型和亚细胞区室。原始研究支持的已有认识与当前项目观察分别保存；每条已有认识可连接 DOI，每项项目观察连接实际数据或图件。领域背景用于检查生物学合理性和推断边界，不会自动把文献共识变成当前项目结论。

## 研究故事怎样形成

论文图中的每个图面都需要承担清楚且不重复的任务，例如发现主要现象、定位时空或细胞来源、建立机制一致性、提供正交验证、呈现边界或阴性结果、完成跨数据整合。工作台会检查一组图是否形成递进关系，删除只重复同一信息的图面，并保留对结论真正有约束力的阴性或不一致结果。

图面确定后，再连接其统计单位、作图数据、分析程序、排图程序、最终 PDF/SVG/PNG、图注、允许写入正文的结论和原始研究。最终报告从同一版本的[科学证据地图](../scientific-evidence-map.zh-CN.md)读取这些关系。

## 日常展示与完整记录

默认结果页只回答五件事：科学问题、主要观察、解释边界、当前进度和下一步决定。方法版本、运行环境、参数、文件校验和与完整来源关系继续保留在可复现性记录中；只有它们影响解释、阻断下一步或用户主动查看时才展开。

项目可在探索、定稿和投稿准备三种节奏之间切换，已有项目也可以先只读扫描，再由研究者确认图件、作图数据、脚本和图注之间的关系。详见[项目组织与工作模式](../project-governance.zh-CN.md)和[使用指南](../using-biomed-workbench.zh-CN.md)。
