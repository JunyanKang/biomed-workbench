# GO Terminology Evidence

`quickgo-term-evidence` resolves declared Gene Ontology IDs through QuickGO.
It retains the exact identifier, preferred name, ontology aspect, obsolete
state, definition, bounded synonyms, provenance, and explicit not-found state.

This creates a stable terminology record before functional analysis. It does
not retrieve gene annotations, run enrichment, establish pathway activity, or
show a mechanism in the project's data. Those claims require a declared gene
universe, evidence-code policy, multiple-testing control, and project-specific
measurements.
