# 科研写作、发表与转化交付

语言：[中文](publication-and-translation.zh-CN.md) · [English](publication-and-translation.md)

## 科学角色

这一能力方向把研究记录组织成逻辑连贯、可以审查和追溯的科学材料。它连接结论、证据和分析结果，保留阴性与未解决发现，并确保稿件中的修改能够在数据、图表和引用中得到对应。

它覆盖从文献和项目事实到正式科研交付的完整过程，并保留不同任务的边界。

| 任务 | 工作台会做什么 | 需要的主要材料 |
| --- | --- | --- |
| 文献版图与持续追踪 | 组织多来源检索、合并重复记录、核对版本和引用语境，区分支持、限制与冲突 | 科学问题、范围、时间条件、纳入与排除标准 |
| 全文精读 | 建立页码和稳定文本位置，制作逐段中英对照、术语表和图表定位 | 可合法访问的全文、阅读目的、重点问题 |
| 论文规划与写作 | 固定研究事实、核心论点、证据范围和章节任务，撰写标题、摘要、正文或方法与结果 | 项目数据、图表、分析记录、参考文献、文章类型 |
| 学术语言修订 | 先识别结构、证据和表达问题，再改写并核对科学内容是否保持一致 | 原文、允许修改的范围、作者范文或目标语言风格 |
| 基金与项目申请 | 按资助机构、年度和项目类型审查科学问题、总体论证、研究目标、可行性证据、独立价值和备选方案 | 当年官方申请书、申请指南、真实前期基础、研究条件和申请人材料 |
| 统计与数据可用性 | 核对实验单位、重复结构、统计报告和图注，整理数据、代码、材料与访问方式 | 研究设计、统计结果、图注、数据和代码清单 |
| 期刊与投稿规范 | 根据科学范围、读者、文章类型和证据成熟度推荐期刊并逐项检查稿件 | 项目摘要或稿件、目标读者、发表限制 |
| 图件、审稿与修订 | 规划图和图注，模拟审稿，制作逐条回复并追踪实际修改位置 | 源数据、现有图稿、编辑与审稿人原文、稿件版本 |
| 汇报与专利材料 | 制作并复查真实演示文件，或组织有来源支撑的技术披露与专利草稿包 | 听众与时长、源图表，或完整技术披露和证据材料 |

其中，文字生成、科学判断和项目叙事由统一研究入口结合实际证据完成；确定性的审查模块负责检查内容保持、统计报告、数据可用性、稿件修订和交付文件。通过通用模块检查不代表某一篇稿件已经达到投稿状态，最终判断仍以该稿件、目标期刊和本次交付检查为准。

## 统一发表方案

工作台先识别任务是论文写作、基金申请、同行评议、演示还是专利相关准备，再核对现有证据是否足以支持相应交付。涉及投稿时评估期刊和文章类型；涉及写作时先建立核心论点、章节任务和图件关系；涉及修订时检查引用、陈述、时间关系和结论是否得到证据支持，并用回复矩阵和修订记录组织需要完成的修改。专利和演示材料只使用已经完成评审的证据，同时保留未解决问题。

稿件修订、审稿回复、专利准备和演示材料会分别审查，因为它们面对的读者、用途和质量要求并不相同。

## 文献检索与全文精读

工作台可以围绕一个研究问题组织多来源检索，核对 DOI、PMID、题名、作者和版本，合并重复记录，并区分直接支撑、部分支撑、背景信息、限制性证据和相反结果。期刊名称和引用次数只用于帮助安排阅读顺序，不能代替对摘要、全文和具体主张的核对。

当用户需要持续追踪一个主题时，可以把检索式、来源、时间范围、排除条件、评分维度和交付周期固定下来，每次保留新增、重复、撤稿或更正记录及其变化。候选文献可以按主题相关性、主张直接性、方法匹配、证据深度、新颖性和时效性排列阅读优先级；这些分数服务于筛选，不代表研究质量或结论真伪。对“独立他引”的判断会核对作者、机构和具体引用语境，不能仅凭引用次数或期刊名称确定。

对于全文精读，工作台先保留页码和稳定的文本位置，再生成逐段原文与中文对照、术语表、翻译说明，以及靠近相关文字放置的图表。数字、公式、引用标记、基因与蛋白名称、单位和原文中的不确定性保持不变。后续问题会回到相应页码和文本位置回答，而不是依赖对话记忆。

全文只通过开放获取或用户已经获得授权的机构访问渠道取得。下载记录会区分 PDF、HTML 全文、摘要和仅有元数据的记录，并核对文件格式、页数和校验值。遇到登录、验证码或出版平台安全检查时，由用户在浏览器中完成；工作台不读取或保存密码、验证码、cookie 或会话信息。

## 科研写作与基金申请

论文写作从研究事实、核心论点、证据范围、读者、文章类型、章节任务和术语表开始。每段文字承担一个明确作用，重要主张与数据、图表或引用保持邻近；证据不足的内容会保留为待补信息或假设，不会被流畅文字掩盖。

语言修订先列出结构、证据和表达问题，再在原有科学内容与约定结构内改写，最后逐项比较原文和修订稿。检查内容包括数字、结果、公式、引用、专业术语、段落和标题结构，以及主张的语气是否超过证据强度。修订会清除模板化开场、宣传性表述、空泛强调、堆砌引用、过长句和破折号，同时保留必要的谨慎措辞、被动语态、第一人称复数和正式定义。交付内容包括修订稿、简短修改说明和内容保持检查结果。

基金和项目申请使用单独的论证流程。工作台会先整理研究范围、事实与约束、主张—证据表、核心科学问题、总体论点、各章节允许和禁止出现的主张，以及每个研究目标的依据、方法、预期结果、可行性证据、独立价值和备选方案。资助机构通过精确身份匹配，不会因名称相近而串用要求。愿景可以有力度，但初步结果、既往工作、合作关系、设施和支持信必须来自作者提供的真实材料。

国家自然科学基金申请使用独立的 2026 年配置，区分青年 C、青年 B、青年 A、面上、地区、重点和重大项目。面上与青年 C 按官方改版要求处理三部分正文和 30 页原则；其他类型必须绑定从科学基金网络信息系统下载的当年模板，未知字数不会用网络经验填补。写作前先完成多来源文献检索、核心论文原文精读、引用身份核验、主张—证据复核和课题相关公共数据库取证。工作台可以从研究事实、前期结果和已有草稿开始，完成中心问题、科学假说、章节论证和研究目标的重构，并继续撰写或修改实际正文，不以检查报告代替成稿。立项依据、科学假说、研究方案、技术路线、前期基础和学术贡献主线图使用不同的内容规则；组织、细胞、分子、实验模型和真实数据承担主要视觉叙事，准确标签和关系在可编辑图件中重建，并在最终插入尺寸下反复校对。后续复核覆盖中文段落逻辑、核心表型与机制的一致性、候选底物和因果结论的证据强度、术语命名，以及 Word 引文编号和逐页交付质量。详见[国家自然科学基金申请书研究与写作](nsfc-proposal-writing.zh-CN.md)。

## 统计报告与数据可用性

统计报告审查会明确实际实验单位，区分生物学重复、技术重复、重复测量和嵌套观测，并核对随机化、盲法、排除标准、缺失数据、模型与检验、假设、多重比较、效应量、不确定区间、精确 P 值策略和软件版本。细胞、图像、视野、重复读数或技术重复不会在没有设计依据时被当作独立样本。图注中的样本量、误差线、比较对象和检验方法与正文使用同一套定义。

数据可用性从支撑正文和补充结果的完整数据清单开始，包括原始数据、处理后数据、源数据、模型、图像、表格、软件输出和复用数据。每项数据都对应公开仓储、受控访问、随文提供、复用来源、第三方限制、具有充分理由的申请获取或不适用中的一种方式。公开与受控数据需要明确仓储和稳定编号；受限数据需要说明限制原因和申请流程。代码、材料和实验方案分别说明，具体表述以目标期刊的现行要求为准。

## 期刊定位与稿件要求

期刊定位使用逐刊维护的规范评估项目，内容包括：

- 读者群与科学范围；
- 偏好的文章类型与项目匹配特征；
- 预期稿件章节和语言风格；
- 当所选文章类型存在精确值时，记录篇幅、摘要、参考文献、展示项目与其他数值约束；
- 图件、报告和政策要求；
- 评估所使用的作者指南；
- 评估所采用的规范版本和复核日期。

期刊排序综合考虑科学范围、读者、文章类型和证据匹配度。稿件会逐项对照所选期刊的要求；当数值要求不明确或取决于具体文章类型时，该项会保留为人工确认，不能据此声称已经可以直接投稿。

所采用的规范版本会与推荐和审查结果一同保存，以便后续修订仍按同一要求比较。详见[期刊定位与稿件规范](../journal-standards.zh-CN.md)。

## 科学图件与稿件

- 根据科学结论、源数据、不确定性和图中各部分的验证需求制定图件规格。
- 审查稿件准备度、引用元数据、陈述覆盖度、时间一致性和主张—证据完整性。
- 建立稿件修订基线，逐次记录由审查意见推动的修改。
- 保持未修改的稿件块不变，并验证所声明的分析、实验、图件、引用和回复位置。

论文图先确定要支持的结论、各部分的证据作用、统计信息、源数据、最终尺寸和导出格式，再选择图形和排版。通用定量图在图形类型适用时，可由登记数据直接生成包含 PDF、SVG、PNG、逐图面作图数据、完整规格、校验值和回读报告的图件交付包；复杂方法专属诊断图仍使用相应分析模块。机制示意图或图形摘要属于基于既有证据的说明性图件，不能增加未经研究支持的机制、方向或数值。跨分析统一的字体、线条、颜色、标注、图例、版面和质量复核见[科学作图规范与图件交付](scientific-figure-standards.zh-CN.md)。

当目标期刊尚未确定，或作者指南版本尚未确认时，工作台会先完成期刊定位，再进入稿件审查。

## 同行评议与修订

- 产出与主张连接的审稿评估，区分重大有效性问题和表达问题。
- 建立审稿人回复矩阵，保留证据、行动、稿件位置和未解决冲突字段。
- 审查研究设计、分析结果、方法、图件和结论之间的一致性。
- 当审稿意见存在实质冲突时，要求作出编辑优先级决策。

模拟审稿与作者回复保持不同角色。模拟审稿只依据提供的稿件、图表和证据提出意见；逐条回复则保留编辑和审稿人的原意，并把每项答复连接到真实修改、分析、实验、图表、引用或作者待补信息。没有实际完成的工作不会写成已经完成。

## 转化与知识产权

- 审查科研发明披露的证据、新颖性表述、充分公开、贡献人和未解决的权属或披露问题。
- 将每个拟议权利要求特征追溯到声明的源文本块，并区分 `explicit`、`inherent`、`needs-confirmation` 和 `unsupported` 支持状态。
- 防止正式权利要求撰写静默带入尚未支持或仍需确认的特征；这些特征作为明确的后续工作保留。
- 在正式审查前，检查边界明确的中文权利要求草稿是否连续编号、前向或缺失引用、确认占位符和结果导向表述。
- 跨源映射、证据台账、权利要求特征图、术语、公式、图件、说明书、摘要和声明的交付阈值验证结构化专利草稿。
- 生成适合技术草稿复核的黑白 SVG 方法流程图。
- 连接分子、组学、临床和实验证据以形成转化假设，不把预测与验证混为一谈。
- 为论文、审稿、回复、专利或演示流程准备研究包，同时保留面向不同读者的边界。

这些功能用于科研和技术材料准备，不提供法律结论；正式专利文本仍需由有资质的专业人员复核。

## 交付前检查

引用标记不等于主张支持证明。已完成的分析不会自动获得发表适配性。当证据缺失、结构改动未声明、审稿意见提取不完整、位置无法解析、占位符仍存在或修订记录无法验证时，稿件修订会被阻断。专利与转化产物保留不确定性，不取代法律或监管复核。

## 典型交付物

全文中英对照阅读文件、来源定位表、术语表、多来源文献版图与持续追踪记录、文献与下载清单、数据可用性声明、统计报告审查、论文和基金申请文本、图件计划、方法、证据表、审稿报告、回复信、回复矩阵、修订记录、引用与主张审查、专利披露、演示文件和质量报告，以及限制明确可见的最终研究包。

演示材料会根据听众组织叙事线，把关键发现与证据对应起来，按内容规划页面，并保留所用图表的来源和裁切记录。实际演示文件会在交付前重新打开，检查页面数量、外部素材、文字密度和未解决的严重问题，再进行逐页视觉审查。
