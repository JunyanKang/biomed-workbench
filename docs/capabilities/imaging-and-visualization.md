# Navigation For Image And Figure Capabilities

Languages: [English](imaging-and-visualization.md) · [中文](imaging-and-visualization.zh-CN.md)

Image and figure tasks belong to two independent capability areas:

- [Quantitative Image Analysis](quantitative-imaging.md), which obtains segmentation, colocalisation, trajectory, migration, and registration measurements from images;
- [Scientific Figure Standards And Delivery](scientific-figure-standards.md), which applies project-wide rules for figure purpose, visual standards, source data, layout, export, and rendered-output review.

They can connect within one project: quantitative image analysis first produces reviewed measurements, and scientific figure support then handles communication and delivery.
