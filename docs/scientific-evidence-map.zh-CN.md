# 科学证据地图、版本管理与双语报告

Biomed Workbench 把项目保存为持续演进的科学论证，而不是只保留成功输出的文件夹。地图分为两层：

1. **项目主线图**：只显示图组或关键数据之间支持、削弱、冲突和依赖关系，让读者先看懂完整研究故事；
2. **单项证据展开图**：对每份数据或每个图组依次追踪前置结论、登记数据、作图数据、分析程序、排图程序、最终数据与图文件、图注、叙述来源和原始研究 DOI。

每个文件绑定工作区内可跳转路径、媒体类型、大小和文件校验指纹。报告生成前重新检查路径与指纹；文件缺失或改变会阻止生成。供系统核对的关系记录与阅读版地图来自同一组关系，二者的校验值共同进入双语报告。

## 分析前准入

每个分析节点执行前必须登记：

- 中英文科学依据和可证伪假设；
- 方法、官方说明与主要方法来源；
- 备选方案和选择理由；
- 假设条件与逐参数依据；
- 预期产物；
- 接受、证伪和阻断标准。

信息不足的节点可以保留为计划，但不能被当成已授权分析或有效证据。

证据地图明确区分两种用途。`project-snapshot` 用于如实展示已通过资格审查的输入、待执行分支、失败、冲突与排除项；它不满足论文或其他正式交付的放行条件。`validated-delivery` 只接纳已经形成“计划节点—真实执行—产物重新读取—双语科学评审—保留决策”完整链条的有效结果，并核对当前计划要求的输出是否已由这些结果覆盖。

## 逐项科学评审与决策

所有数据、表格、模型、图和中间产物均分别接受技术、统计、生物学和稳健性评审。图形需要按图中分区逐项解释，不能用一段总述代替。

评审后可以保留、带限制保留、排除、重跑、换方法、补数据、调整假设或停止分支。只有前两种进入当前有效证据集。排除不会删除历史，失败、冲突和负结果仍参与后续判断。

## 版本与报告

证据地图采用不可覆盖的版本目录，每个版本记录父版本、变更原因、登记内容和校验信息。地图文件、版本索引、当前版本指针和项目状态登记通过带恢复记录的发布事务提交；若过程被中断，只读恢复检查会明确标出暂存、未入索引或未登记到项目状态三类状态，不会静默删除文件。中英文报告只能从同一张通过验证的地图生成，并覆盖每项产物的科学依据、方法、结果、结论、限制、决策和对下一步的影响。报告生成器不得自行重新拼接来源。

完整数据结构和实现说明见 [Scientific Evidence Map](scientific-evidence-map.md)。
