# 科学证据地图与双语报告

语言：[中文](scientific-evidence-map.zh-CN.md) · [English](scientific-evidence-map.md)

科学证据地图用于说明一个项目的结论是怎样形成的。它不只保存最终成功的图表，也保留分析依据、输入数据、质量检查、相互矛盾的结果、未被采用的分支和后续决策。

## 两个阅读层次

第一层是项目主线，只展示关键数据或图组之间的关系，帮助读者快速理解研究问题、主要发现和证据缺口。

第二层展开每份数据或每个图组，依次连接：

- 支撑当前分析的前置数据和结论；
- 当前数据、统计结果或图组；
- 用于作图的数据和分析程序；
- 排版程序以及最终的数据、PDF 和 PNG；
- 图注、解释来源和原始研究 DOI。

每个文件都记录可跳转路径和内容指纹。HTML 页面把登记数据、作图数据、分析程序、排图程序、最终数据、PDF、PNG、图注和原始研究分别做成直接入口。报告生成前会重新核对文件；文件缺失或内容已经改变时，系统会停止生成，以免报告引用错误版本。

## 分析为什么可以开始

重要分析开始前需要写明：

- 科学依据和可以被数据反驳的假设；
- 所选方法、主要来源和备选方案；
- 实验单位、统计设计和关键参数依据；
- 预期结果以及接受、质疑或停止该分支的条件。

信息不足时，分析可以保留在计划中，但不会被写成已经执行或已经得到支持的结论。

## 结果怎样进入项目结论

数据、表格、模型和图组会分别接受技术、统计、生物学和稳健性检查。多部分图需要逐部分解释，不能只给整张图写一段笼统总结。

评审后可以选择保留、带限制保留、排除、重新分析、更换方法、补充数据、调整假设或停止该分支。只有已经保留的结果才用于支撑当前结论；被排除的结果、失败分析和冲突证据仍会保存在项目记录中，便于理解决策过程和避免重复犯错。

重新分析或更换方法会建立新的分析分支，并记录改变了什么、为什么改变以及结论适用范围是否发生变化。历史结果不会被覆盖。

## 版本与报告

每次正式更新都会形成一个新版本，记录前一版本、变更原因和所包含的证据。旧版本保持不变，因此可以回看任何结论在当时所依据的数据和分析。

每个版本都提供一个 `index.html` 阅读入口，并生成中文和英文项目解读报告以及中文和英文科学证据地图。HTML 是主要阅读格式，包含：

- 固定目录和组内跳转；
- 中文、英文报告与证据地图之间的切换；
- 结果优先的摘要页，方法、复现信息和完整校验值按需展开；
- 可点击的数据、程序、图件、图注和 DOI；
- 项目结果关系图，以及从前置结论到当前结果、作图数据、程序、最终图件和文献的逐项证据链；
- 适合桌面、窄屏和打印的统一排版。

中文和英文报告从同一版本的证据地图生成，逐项覆盖：

- 科学依据与假设；
- 分析方法；
- 结果与科学结论；
- 图中各部分的具体解读；
- 局限、冲突证据和采用或舍弃的理由；
- 对下一步研究的影响。

这样可以保证两种语言使用同一组数据、图、引用和决策，不会各自重新拼接来源。Markdown 报告继续保留，便于纯文本审阅和旧项目兼容；JSON 地图和 TSV 关系表继续作为机器读取和复核入口。
