# 期刊定位与稿件规范

Biomed Workbench 根据研究范围、目标读者、文章类型、研究设计、证据成熟度和转化价值评估期刊适配性。输出不是简单列出刊名，而是形成有依据的候选方案：逐项说明项目为何适合、当前短板在哪里，以及哪些证据补充或稿件调整能够实质改善匹配度。

## 评估内容

- 期刊读者、研究范围与主要文章类型；
- 研究设计、机制深度、验证层级与编辑定位之间的适配性；
- 稿件必需部分、声明与研究设计对应的报告规范；
- 目标文章类型适用的摘要、正文、参考文献和图表数量要求；
- 图件结构、源数据、图像完整性与无障碍表达要求；
- 数据、代码、研究资源、伦理、试验注册和利益冲突等声明；
- 标题、摘要和正文的语言风格，以及观察、关联、机制和因果结论之间的边界。

## 使用方式

提供项目科学问题、研究设计、主要发现、验证层级、目标读者，以及文章类型或发表路径方面的限制。如果已有稿件，还应提供章节、字数、图表、声明和报告清单。工作台将返回期刊适配论证、文章类型建议、逐字段规范审查和按优先级排列的修改方案。

每次评估都会绑定所采用的期刊规范版本和复核日期。更换目标期刊、文章类型或作者指南发生更新时，需要重新评估。未明确或存在歧义的要求会保留为待核实项，在解决前不会给出“可直接投稿”的结论。
