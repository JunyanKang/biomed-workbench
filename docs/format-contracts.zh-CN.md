# 科学数据格式契约

Biomed Workbench 不用扩展名猜测科学数据。每个格式条目由名称和规范版本共同确定，并声明：

- 表示形式与压缩方式；
- 必要索引和排序；
- 坐标体系、参考序列及其校验指纹；
- 基因组版本、注释版本和标识符命名空间；
- 样本清单、方向、处理层级、必要元数据和文件角色。

BAM/CRAM、VCF、BED、GTF/GFF3、fragments、count matrix 和通用表格各自拥有独立规则。通用表格不能替代带坐标含义的专用格式。PNG、JPEG 和 WebP 只描述静态图像交换；定量图像还需要额外的位深、像素尺寸、颜色与测量语义。

未知版本、缺少索引、坐标或参考不一致、样本清单缺失以及文件角色不完整，都会在科学工具执行前阻断流程。系统不选择“最接近的版本”，也不会因为文件后缀相同而放行。

完整英文规范见 [Format Contracts](format-contracts.md)。
