# 文件与数据要求

语言：[中文](format-contracts.zh-CN.md) · [English](format-contracts.md)

Biomed Workbench 不会只根据文件扩展名猜测数据内容。运行分析前会根据数据类型检查文件格式、参考版本和必要元数据。

## 通用检查内容

- 表示形式和压缩方式；
- 必要的索引和排序；
- 坐标体系、参考序列和基因组版本；
- 注释版本和基因或变异标识符体系；
- 样本表、方向性、处理层级和文件在分析中的作用。

BAM/CRAM、VCF、BED、GTF/GFF3、单细胞 fragments、表达矩阵和普通表格有不同要求。普通表格不能代替具有基因组坐标含义的专用格式。

表达矩阵需要明确行列分别代表什么、数值是原始计数还是处理后的值、使用哪种特征标识符，并同时提供与矩阵对应的特征和样本信息。

PNG、JPEG 和 WebP 适合普通静态图像交换。用于定量分析的图像还需要位深、像素尺寸、颜色空间、通道和测量含义，不能只提供一张经过展示处理的图片。

## 哪些问题会阻止分析

未知或不支持的格式版本、缺少必要索引、坐标和参考不一致、样本信息缺失、矩阵行列身份不清以及文件作用无法确定，都会在科学软件运行前被指出。工作台不会选择一个“最接近”的版本，也不会因为后缀相同就继续执行。

具体方法还可能要求额外字段和配套文件；这些要求会在分析开始前与用户项目逐项核对。
