# 0.2.2 · 2026-08-20

[English](2026-08-20-0.2.2.md) · [中文](2026-08-20-0.2.2.zh-CN.md) · [Release index](README.md)

This documentation patch makes the complete academic-writing and research-delivery capability visible from the public entrypoints. The underlying scientific modules, compatibility rows, execution implementations, and observed biological evidence are unchanged from 0.2.1.

## Public writing workflow

- The project home now has a dedicated academic-writing and research-delivery section rather than compressing the capability into one research-layer row.
- The public workflow connects literature discovery and full-paper reading, manuscript and proposal drafting, scholarly prose revision, statistical reporting, data and code availability, journal positioning, citation review, paper figures, peer-review response, presentations, and patent-related technical preparation.
- Natural-language examples show how to request manuscript drafting, proposal review, and evidence-linked point-by-point responses without knowing module names.
- The capability guide states the material required for each task and distinguishes evidence-based prose generation from deterministic delivery audits.

## Delivery boundaries

- Passing a generic writing audit does not make a particular manuscript submission-ready.
- Language revision retains a separate content-preservation check for numbers, results, equations, citations, terminology, structure, and claim strength.
- Journal recommendation, mock review, and manuscript checks remain decision support until the current manuscript, evidence, target requirements, and final files have been reviewed together.

## Regression protection

A bilingual release-surface test now requires the README and usage guides to expose full-paper reading, manuscript and proposal writing, scholarly revision, statistical reporting, data availability, peer review, and translational delivery. Local links and the complete release surface are checked before publication.
