# 0.2.4 · 2026-08-24

[English](2026-08-24-0.2.4.md) · [中文](2026-08-24-0.2.4.zh-CN.md) · [Release index](README.md)

This release corrects the public capability structure and internal scientific taxonomy so measurement from images and communication through scientific figures have distinct, stable responsibilities. Scientific methods, executors, quality thresholds, and existing representative acceptances are unchanged.

## Capability structure

- **Quantitative image analysis** belongs to data scales and research objects. It covers image inspection, segmentation, colocalisation, object tracking, migration measurements, and baseline registration while preserving masks, object-level data, and measurement QC.
- **Scientific figure standards and delivery** are project-wide support. Bulk, single-cell, spatial, structural, clinical, experimental, and quantitative-imaging work share rules for figure purpose, typography, strokes, colour, legends, statistical annotations, layout, source data, export, and rendered-output review.
- **Scientific communication images** form a separate explanatory-material class for mechanism illustrations, graphical abstracts, and bounded communication-image processing. They remain distinct from quantitative image evidence and source-data-bound figure delivery.

## Documentation and compatibility

The README and bilingual capability maps now use separate sections for data scales and research objects versus project-wide support. Dedicated guides cover quantitative image analysis and scientific figure standards. The former combined page remains as concise navigation so existing links continue to resolve.

## Taxonomy gates

The generated module taxonomy adds a capability-scope facet that separates image-derived measurements, project-wide figure support, and scientific communication images. Regression checks require figure specification and figure delivery to remain cross-scale, quantitative imaging modules to remain measurement-specific, and public entrypoints to keep the two capability classes separate.

## Release scope

The release continues to register 208 scientific modules. This change reorganises capability classification, documentation, and the taxonomy report; it does not reinterpret or upgrade any existing scientific execution evidence.
