# 0.2.9 · 2026-08-31

[中文](2026-08-31-0.2.9.zh-CN.md) · [English](2026-08-31-0.2.9.md) · [版本索引](README.zh-CN.md)

本版本把项目解读报告和科学证据地图升级为可直接阅读与跳转的 HTML 交付包。科学内容仍只从通过完整性检查的同一版本证据地图生成；展示方式的改进不会重写结论、路径、来源或校验值。

## HTML 项目解读报告

- 每个证据地图版本新增 `index.html` 阅读入口，以及中文、英文两份 HTML 项目解读报告。
- 报告采用结果优先布局：观测结果和科学结论首先呈现，科学依据、分析方法、参数理由、复核意见和完整校验值按需展开。
- 左侧目录可以直接跳转到项目概览、证据组和具体数据或图组；中文报告、英文报告、证据地图和机器文件可以在页面顶部切换。
- 登记数据、作图数据、分析程序、排图程序、最终数据、PDF、PNG、图注和原始研究均提供直接链接，并显示文件角色、项目内路径和 SHA-256。

## HTML 科学证据地图

- 新增中文和英文科学证据地图页面。项目主线只显示已登记的跨图组关系，选择节点即可跳转到相应证据单元。
- 每个数据或图组按“前置数据或结论—当前结果—作图数据—分析程序—排图程序—最终数据与图件—图注—研究来源”展开，多个同级文件保持并列。
- 页面使用内嵌样式和确定性 SVG，不依赖外部网页脚本或样式服务；科学文本经过转义，文献链接使用证据地图中已经校验的 DOI。
- 排版适配桌面、窄屏、深色显示和打印，长路径与完整校验值能够自动换行。

## 兼容性与版本管理

- 旧版 Markdown 中文报告、英文报告和证据地图继续生成，避免现有项目和纯文本工作流中断。
- JSON 证据地图和 TSV 文件关系表继续保留，作为机器读取、版本核对和报告再生成的依据。
- 新增 HTML 文件与原有文件一起写入不可变版本目录并登记校验值；任何文件缺失或改变都会使版本验证失败。
- 发布注册表仍包含 221 个模块和 222 条兼容性记录；本次更新改进交付格式，不改变既有科学方法成熟度。

## 验证
