# 0.2.11 · 2026-09-03

[English](2026-09-03-0.2.11.md) · [中文](2026-09-03-0.2.11.zh-CN.md) · [Release index](README.md)

This release completes an executable writing-delivery path for manuscripts, reports, and research proposals. Writing is no longer organised directly by pasted order, method order, or significance. Reviewed literature context and project evidence are first assigned scientific roles, then revised for language and delivered as an inspectable artifact.

## Scientific Argument

- Evidence is organised as field premise, knowledge gap, discovery, source or context, mechanistic consistency, orthogonal validation, negative boundary, and integration while respecting declared upstream dependencies.
- Null and discordant findings that constrain the central claim are retained. At least one biologically plausible competing explanation and a discriminating observation are required.
- Manuscripts and proposals use distinct argument rhythms. Dated writing profiles define section tasks and reader expectations for Nature, Cell, Science, JAMA, NEJM, and The Lancet.

## Biomedical-Language Revision

- Dedicated checks identify internal-state, software-engineering, process-management, and audit-like prose and replace it with concrete biological entities, observations, inferences, limitations, and testable predictions.
- Necessary software names, algorithms, parameters, data structures, and quantitative results remain intact in computational Methods.
- Pre- and post-revision comparison verifies numbers, results, equations, citations, technical terms, mechanistic boundaries, and evidence-calibrated uncertainty. Text that fails content preservation cannot enter final delivery.

## HTML Writing Report

- The new `biomedical-writing-delivery` module writes accepted text to a content-addressed version directory with an HTML reading page and JSON record.
- The page provides navigation to the scientific question, evidence order, original and revised text, unresolved findings, project evidence, literature DOIs, and target-venue guidance.
- The written page is reopened and checked for navigation, links, content, and checksums. An in-memory review object, route, or plan is no longer treated as writing delivery.

## Validation

The controlled writing case completed real file creation and reload, page-structure checks, portable evidence links, DOI links, and content verification. The complete local suite ran 1,370 tests: 1,368 passed and 2 were skipped under declared conditions. Release validation, the 6/6 strict health check, and plugin-contract validation passed. Formal publication still requires every remote continuous-integration job for the same commit to succeed.
