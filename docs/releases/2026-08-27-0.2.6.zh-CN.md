# 0.2.6 · 2026-08-27

[中文](2026-08-27-0.2.6.zh-CN.md) · [English](2026-08-27-0.2.6.md) · [版本索引](README.zh-CN.md)

本版本重新组织中英文项目首页，并补齐论文和科研项目书的语言修订闭环。各项科学方法的能力范围和证据等级仍由对应模块的独立契约约束。

## 中英文项目首页

- 中文和英文 README 均从用户的研究问题出发，说明研究设计、多尺度数据、分析、结果解释和科研交付之间的关系。
- 能力分类将数据尺度与研究对象同贯穿项目的文献、数据库、整合分析、科学作图和科研写作支撑明确分开。
- 中文与英文首页分别使用带本语言准确标注的概念图，保持统一且克制的视觉风格；最后阶段是科研交付，不暗示插件已经实施实验。
- 安装方式保留为面向 Codex 的简短自然语言请求，详细使用方法、能力边界、科学证据地图和版本信息通过双语文档索引展开。

## 论文和项目书的学术表达修订

- `academic-prose-revision-audit` 现在会根据文体返回不同的修订要求。论文采用克制、以结果为中心的学术表达；项目书在真实前期证据和可行方案支撑下保留清楚有力的科学愿景。
- 每次论文或项目书修订都必须经过写前检查、保持科学内容的实际改写，以及原稿与修订稿的写后逐项比较。
- 数字、结果、公式、引用、专业术语、机制边界和有证据依据的不确定性受到保护。作者范文只用于学习句子节奏、衔接习惯、谨慎程度和术语偏好，不复制项目专属表述。
- 改动受保护内容、把结论提高到证据不能支持的强度，或未通过写后复核的文本，不能作为最终稿交付。

## 项目书摘要与生命科学语言

- 中文摘要在正文稳定后完成，并按当前 2026 配置控制在 400 字以内，标点计入长度。
- 英文摘要以中文摘要的科学论证为基础，不另设工作台字数限制；它保持相同的研究对象、机制边界、研究目标、不确定性和预期知识增量，不逐字翻译，也不增加中文正文中没有的结论。
- 全文从题目到图注和参考文献进行统一修订，把内部工程、审计和软件编排语言改写为自然的生命科学论证，同时保留真实的计算方法、参数和定量事实。
