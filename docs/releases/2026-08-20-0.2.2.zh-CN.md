本次文档补丁让科研写作与科研交付的完整能力可以从公开入口直接发现。科学模块、兼容性配置、执行实现和已经观察到的生物学证据均与 0.2.1 保持一致。

## 公开写作流程

- 项目首页新增独立的论文写作与科研交付板块，不再把这部分能力压缩成研究层级表格中的一行。
- 公开流程完整连接文献检索与全文精读、论文和基金写作、学术语言修订、统计报告、数据与代码可用性、期刊定位、引用核查、论文图、审稿回复、演示和专利相关技术材料。
- 自然语言示例说明如何直接提出稿件撰写、基金审查和有证据位置的逐条回复任务，不需要用户记忆模块名称。
- 能力说明列出每类任务需要的主要材料，并区分基于项目证据的文字生成与确定性的交付审查。

## 交付边界

- 通用写作审查通过，不代表某一篇稿件已经达到投稿状态。
- 学术语言修订单独检查数字、结果、公式、引用、术语、结构和结论强度是否保持一致。
- 期刊推荐、模拟审稿和稿件检查仍属于决策支持；只有当前稿件、项目证据、目标要求和最终文件一起通过复核，才能形成相应的项目级交付判断。

## 回归保护

新增双语发布界面测试，要求 README 和使用指南持续展示全文精读、论文与基金写作、学术语言修订、统计报告、数据可用性、同行评议和转化交付。发布前同时检查本地链接和完整发布界面。
