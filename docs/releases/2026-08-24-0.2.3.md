# 0.2.3 · 2026-08-24

[English](2026-08-24-0.2.3.md) · [中文](2026-08-24-0.2.3.zh-CN.md) · [Release index](README.md)

This release adds executable publication-figure delivery and translates useful design principles from an external scientific-plotting project into a fixed Workbench contract. The capability does not depend on copying example scripts, manually editing templates, or reusing example pixels.

## Publication-figure delivery

- Render final-size PDF, editable SVG, and 600-dpi PNG files from explicitly registered CSV or TSV data and a closed figure specification.
- Preserve panel source data, the frozen specification, a file manifest, content digests, and an independent quality report in the same delivery package.
- Directly support scatter, line, precomputed bar, box, violin, heatmap, and volcano panels; method-native diagnostics remain with their analysis modules.
- Require a claim, column mapping, and selection rule for each panel. The renderer does not infer semantics from column names, silently discard rows, run undeclared tests, or reject a valid null result.
- Reopen vector, raster, and source-data files to check final dimensions, resolution, editable text, registered-row coverage, and label overlap, followed by visual review of the actual render.

## Information-dense acceptance

The release acceptance uses the public Breast Cancer Wisconsin (Diagnostic) dataset to test rendering and delivery only; it makes no diagnostic or biological claim. Its six-panel figure contains a 20 by 20 correlation matrix, 1,138 case-level points, 30 feature effects with multiplicity-adjusted results, two group trends, and 20 ranked features across 1,228 registered rendering records. Every record reaches a declared panel, automated text-box overlap is zero, and the PDF, SVG, PNG, editable vector text, and panel source tables all reopen successfully.

## Source assimilation and verification

All 217 tracked files at the selected `TingxiYu/academic-figure-skill` commit have a recorded digest, classification, and disposition. The retained ideas are claim-first design, final-size typography review, joint vector and raster delivery, panel-source preservation, and combined code/render review. Example scripts, previews, host adapters, and hard-coded data are not runtime dependencies. The repository keeps a fast controlled regression, the information-dense public-data acceptance, execution through the registered command, and routing coverage.

## Release scope

This release registers 208 scientific modules. Acceptance of the new figure module establishes rendering, packaging, and reload behavior for the declared inputs and tested software combination; project data quality, upstream statistics, scientific interpretation, and target-journal production requirements still require project-specific review.
