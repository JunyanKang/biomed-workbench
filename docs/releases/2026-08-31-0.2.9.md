# 0.2.9 · 2026-08-31

[English](2026-08-31-0.2.9.md) · [中文](2026-08-31-0.2.9.zh-CN.md) · [Release index](README.md)

This release upgrades project interpretation reports and scientific evidence maps into a navigable HTML delivery package. Scientific content still comes only from the same integrity-checked evidence-map version; presentation changes do not rewrite conclusions, paths, sources, or checksums.

## HTML project interpretation reports

- Each evidence-map version now provides an `index.html` reading entry and Chinese and English HTML interpretation reports.
- Reports use a results-first layout: observed results and scientific conclusions appear first, while rationale, methods, parameter reasoning, scientific review, and full checksums expand on demand.
- A persistent table of contents links to the project overview, evidence groups, and individual datasets or figure groups. The top navigation switches among both reports, both evidence maps, and machine-readable files.
- Registered data, plot-ready data, analysis scripts, renderers, final data, PDF and PNG figures, captions, and original studies all receive direct links with their role, project path, and SHA-256.

## HTML scientific evidence maps

- Chinese and English scientific evidence-map pages are now generated. The project-level view contains only registered cross-figure relationships, and selecting a node moves to its evidence unit.
- Each dataset or figure group expands from prerequisites through the current result, plot-ready data, analysis, renderer, final data and figures, caption, and research sources. Files at the same stage remain parallel rather than being forced into an artificial sequence.
- Pages use embedded styling and deterministic SVG without external web scripts or style services. Scientific text is escaped, and literature links use DOIs already validated by the evidence map.
- Layouts support desktop, narrow screens, dark colour schemes, and printing; long paths and complete checksums wrap without leaving their containers.

## Compatibility and version management

- The existing Chinese and English Markdown reports and Markdown evidence map remain generated, preserving earlier projects and plain-text workflows.
- The JSON map and TSV relationship table remain the machine-readable source for verification and regeneration.
- New HTML files join the existing artifacts in each immutable version directory and are recorded by checksum. A missing or changed file invalidates version verification.
- The release registry remains at 221 modules and 222 compatibility rows. This release improves delivery format without changing the scientific maturity of existing methods.

## Verification

- New checks cover HTML structure, table-of-contents anchors, cross-page navigation, local evidence links, DOIs, relationship graphics, and immutable version files.
- Real-browser review covers desktop and narrow-screen layout, evidence-link cards, disclosure hierarchy, long-path wrapping, and the reading order of the evidence map.
- The complete local regression suite ran 1,351 tests, with 4 declared skips and all remaining tests passing; release validation and all strict health checks passed.
