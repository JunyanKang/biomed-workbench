# 0.2.10 · 2026-09-03

[中文](2026-09-03-0.2.10.zh-CN.md) · [English](2026-09-03-0.2.10.md) · [版本索引](README.zh-CN.md)

本版本把 Biomed Workbench 从“具备大量方法与追溯规则”进一步收束为结果优先的完整研究路径。默认交互围绕生物学问题、主要观察、证据边界、当前进度和下一步决定展开；分析环境、参数、文件身份和完整来源关系继续保留，但不占据主要结果页面。

## 科学问题与方法选择

- 复杂请求先分别识别实验方法、测量靶标、对照、归一化和生物学关系，再建立独立分析分支与最终综合判断。
- 加入术语消歧和否定约束；“继发转录效应”不会再被解释为 RNA 二级结构。
- 默认采用“一个主分析加一个必要正交验证”的最小充分原则；增加第三种方法时必须说明它替代哪项分析或增加哪项决策信息。

## 结果解释与项目推进

- 新增探索、定稿和投稿准备三种工作节奏，避免在早期探索中过早施加完整投稿要求。
- 新增既有项目只读导入，可盘点图件、作图数据、分析脚本、排图程序和图注，发现冲突版本，并要求研究者逐条确认候选关系。
- 新增带版本的领域背景配置，把文献支持的已有认识与当前项目观察分开，用物种、组织、发育时期、疾病状态和细胞区室参与科学复核。
- 科学解释自我修正以观察、效应量、不确定性、实验单位、阴性结果和竞争性解释为起点；发现重大问题后修改解释、缩小结论、重做或替换分析，而不是只生成检查清单。

## 细胞通讯与分泌信号

- CellChat 使用官方 R 流程按生物学样本建立对象，支持 Matrix Market、Seurat v5 和 SingleCellExperiment 输入，保存逐样本结果，并输出官方 circle、chord 和 bubble 图。
- CellChat 2.2.0 已完成两份独立样本的受控实跑和结果重读，当前成熟度为 `EXECUTED_FIXTURE`；本版本不把它写成公共生物学案例已验证。
- SecAct 通过官方 `SecAct.activity.inference.scRNAseq` 与 `SecAct.CCC.scRNAseq` 接口实现参数化适配，明确区分分泌蛋白相对活性与配体–受体分数。当前验收环境未安装 SecAct，因此该方法保持 `CONTRACT_ONLY`。
- LIANA–CellPhoneDB 的既有公共案例只继续证明该具体方法，不向 CellChat、NicheNet、直接 CellPhoneDB 或 SecAct 转移成熟度。

## 科学图件与研究故事

- 每个论文图面需要承担发现、来源或背景、机制一致性、正交验证、边界或阴性结果、跨数据整合中的一项明确任务；重复同一贡献的图面不会自动进入主图。
- 新增重绘图与参考图的视觉语义比较，检查长宽比例、主体区域、信息密度、调色板和矢量标签；最终仍需核对图形类型、UMAP 或空间几何、颜色含义、裁切、遮挡和图例占比。
- 新增中英文[科学解释、研究叙事与结果决策](../capabilities/scientific-interpretation-and-storytelling.zh-CN.md)文档，并系统更新 README、能力地图、使用指南、项目组织、架构和科学作图说明。

## 成熟度显示

公开页面只使用 `CONTRACT_ONLY`、`EXECUTED_FIXTURE`、`PUBLIC_CASE_VALIDATED` 和 `CURRENT_PROJECT_VALIDATED` 四级。多方法模块只有在全部已声明方法均达到同一级别时才继承总体级别，否则分别列出已经运行或通过公共案例的方法。

## 验证

本地完整测试共运行 1,361 项，1,359 项通过，2 项按既定条件跳过；另外 15 项 pytest 风格的单细胞与空间科学契约通过，伴随 1 条不影响结果的类别提示。发布检查、6/6 严格健康检查和插件契约检查均通过。正式发布还要求同一提交的远端持续集成全部成功，远端结果以本版本提交和 GitHub Actions 为准。
