# 0.2.4 · 2026-08-24

[中文](2026-08-24-0.2.4.zh-CN.md) · [English](2026-08-24-0.2.4.md) · [版本索引](README.zh-CN.md)

本版本修正公开能力分类和内部科学分类轴，使“从图像获得测量结果”和“把研究结果制作成科学图件”分别承担清晰、稳定的职责。科学方法、执行器、质量阈值和既有代表性验收未发生改变。

## 分类结构

- **定量图像分析**归入数据与研究对象，负责图像检查、分割、共定位、目标追踪、迁移定量和基础配准，并保存 mask、逐目标数据与测量质量检查。
- **科学作图规范与图件交付**归入贯穿全项目的支撑能力，为 Bulk、单细胞、空间组学、结构生物学、临床实验和定量图像分析统一图件任务、字体、线条、颜色、图例、统计标注、版面、源数据、导出和成图复核。
- **科研传播图像**作为独立的说明性材料类别，涵盖机制示意图、图形摘要以及传播图片处理；它与定量图像证据和数据图件交付分别管理。

## 文档与兼容性

README 和中英文能力地图采用“数据与研究对象”与“贯穿全项目的支撑能力”两层结构。新增独立的定量图像分析与科学作图规范文档；原合并文档保留为简短导航，使已有链接继续有效。

## 分类门禁

模块分类报告新增能力范围维度，区分图像测量、全项目作图支撑和科研传播图像。回归检查要求论文图件规格与图件交付保持跨尺度通用属性，定量图像模块保持图像测量属性，并禁止公开入口再次把两者合并成同一能力类别。

## 发布范围

本版本登记的科学模块数量保持为 208。此次变更调整能力组织、文档和分类报告，不重新解释或升级任何既有科学执行证据。
