# 0.2.0-dev 发布说明

日期：2026-08-02  
状态：开发快照，发布验收通过

## 本版重点

- 建立覆盖证据、数据分析、分子与结构、临床与实验、成像与可视化、论文与转化交付的 194 个科学模块注册表。
- 完成 bulk 染色质可及性、新生转录、RNA–蛋白结合、核糖体测序、DNA 甲基化、R-loop、RNA 修饰富集和三维基因组的参数化执行入口与分级验收。
- 扩展单细胞批次整合、跨物种整合、多组学整合、参考映射，以及空间平台导入、解卷积、区域识别、多切片对齐和图像联合分析。
- 引入版本化科学证据地图、双语报告门禁、统一作图规范、期刊规范库和面向 Agent 的凭据配置机制。
- 将“契约就绪、执行器就绪、公共数据验收完成”分开登记，避免把能够配置的模板表述为已经完成真实分析。

## 真实执行验收

下列入口执行了外部科学流程，重新读取原生结果，并在清理临时数据前发布路径中立、带校验值的正式证据。

| 分析入口 | 本版验收范围 |
| --- | --- |
| ATAC-seq 与 DNase-seq | ENCODE `ENCSR356KRQ` 与 `ENCSR000EOT`，各保留两个生物学重复；完整 ENCODE ATAC 2.2.3 峰、信号与质量报告均已重新读取 |
| Ribo-seq、GRO/PRO-seq、iCLIP、WGBS、Hi-C | 固定 nf-core/riboseq 1.2.0、nascent 2.3.0、clipseq 1.0.0、methylseq 4.2.0 与 hic 2.1.0；分别重新读取 174、50、22、52 与 14 个科学结果文件 |
| NET-seq | 公开 `SRR12840066` 与 sacCer3；完成 UMI/接头处理、唯一比对、BAM 与正负链末端轨道验收 |
| RIP-seq | RIPSeeker 1.28.0 官方 PRC2 数据；两个 RIP 与一个对照，两次固定随机种子运行得到逐字节一致的 59 个区域和原生 R 对象 |
| LACE-seq | 公开 Ago2 `SRR10173391` 与 IgG `SRR10173407`；完成 Cutadapt 1.15、Bowtie 1.2.3、rRNA 过滤、全读段 IgG 扣除和链特异簇识别 |
| Tangram | Tangram 1.0.4 官方仓库固定提交的完整测试数据；26,431 个参考细胞、18 类细胞、9,852 个空间位置和 249 个共同基因；映射模型与归一化结果均已重新读取 |

## 发布质量

- 注册模块：194。
- 公共数据验收：31 个模块；其余 163 个模块具备可执行并重新读取产物的适配器，但未在本版登记公共数据验收。
- 兼容性证据：195/195 条回归验证与 195/195 条端到端验证通过。
- 自动测试：1,150 项通过，2 项按运行条件跳过；另有 622 个子测试通过。
- 发布验证：通过；模块注册表与格式注册表均与生成物一致。

## 证据续期规则

科学执行代码、参数语义、输入处理或结果识别发生变化时重新计算；运行依赖或兼容性策略变化时只复验受影响的兼容层；模块说明和成熟度变化经过审查后换发对应模块范围；README、发布说明或无关模块变化不会使由同一执行器产生的科学结果失效。
