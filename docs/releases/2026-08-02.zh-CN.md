# 0.2.0-dev 发布说明

- 日期：2026-08-02
- 状态：开发快照，发布验收通过
- 语言：[中文](2026-08-02.zh-CN.md) · [English](2026-08-02.md) · [版本索引](README.zh-CN.md)

## 本版重点

- 建立覆盖证据、数据分析、分子与结构、临床与实验、成像与可视化、论文与转化交付的 198 个科学模块注册表。
- 完成 bulk 染色质可及性、新生转录、RNA–蛋白结合、核糖体测序、DNA 甲基化、R-loop、RNA 修饰富集和三维基因组的参数化执行入口与分级验收。
- 扩展单细胞批次整合、跨物种整合、多组学整合、参考映射，以及空间平台导入、解卷积、区域识别、多切片对齐和图像联合分析。
- 新增 STRING 12.0 蛋白互作网络、HADDOCK3/DockQ/PRODIGY 复合物对接、AlphaFold 3 官方输入输出适配，以及 MSBio2/Metascape–Cytoscape 网络交付；分子与结构图件统一输出可编辑数据、PDF、SVG 和高分辨率 PNG。
- 引入版本化科学证据地图、双语报告门禁、统一作图规范、期刊规范库和 Codex 友好的凭据配置机制；Codex 保持主入口，其他智能体仅通过隔离的 Agent Skills 或只读 MCP 适配层复用同一科学核心。
- 将“契约就绪、执行器就绪、公共数据验收完成”分开登记，避免把能够配置的模板表述为已经完成真实分析。

## 证据续期规则

科学执行代码、参数语义、输入处理或结果识别发生变化时重新计算；运行依赖或兼容性策略变化时只复验受影响的兼容层；模块说明和成熟度变化经过审查后换发对应模块范围；README、发布说明或无关模块变化不会使由同一执行器产生的科学结果失效。
