# 0.2.8 · 2026-08-31

[English](2026-08-31-0.2.8.md) · [中文](2026-08-31-0.2.8.zh-CN.md) · [Release index](README.md)

This release strengthens the continuous path from raw sequencing inputs and public research evidence to a scientific conclusion. The research entry now identifies data and study design before selecting a minimal sufficient analysis. Interpretation leads with observations, effect size, uncertainty, experimental unit, and discordant evidence, while detailed execution provenance remains available in the background.

## Sequencing workflow interoperability

- A new sequencing intake recognizes FASTQ, BAM/CRAM, VCF, single-cell matrices, reference files, and tables, checks paired-read and sample-sheet consistency, and only then selects a downstream route.
- A new readiness check evaluates tools and reference resources separately and reuses a recorded environment first. Tool availability is never presented as completed analysis.
- A new external-run ingest accepts only completed run packages, reloads the outputs, verifies paths, file digests, and analysis-environment identity, and then sends them to assay-specific quality control and scientific review.
- When Life Sciences NGS Analysis is also installed, Biomed Workbench can use its specialist execution for BCL conversion, raw-read QC, variant calling, amplicon and metagenomic analysis, and chemistry-aware count generation, then return completed results to the unified research path. The core capabilities remain standalone.

## Public life-science evidence

- Fixed official query operations now cover GWAS Catalog, ChEMBL, PRIDE, BioStudies, ENCODE, Human Protein Atlas, and MGnify. Callers cannot replace the registered host or construct arbitrary request paths.
- Cross-source evidence normalization retains entity, species or assembly, evidence type, observation, original record, and source link while separating project observations, genetic association, expression context, bioactivity, public datasets, and mechanistic evidence.
- When Life Science Research is also installed, its more granular database skills can perform a targeted retrieval before workbench normalization and interpretation. The seven built-in sources remain available without that plugin.
- The current implementation completed no-retry live verification for all nine registered query operations; each returned HTTP 200 and at least one reloaded record.

## Scientific interpretation and correction

- A new scientific-review correction capability checks effect estimates, uncertainty, independent replication, statistical unit, negative or discordant results, causal language, and whether the next experiment discriminates competing explanations.
- If a claim exceeds the study design or lacks essential quantitative evidence, the workflow requires reanalysis, additional evidence, or a narrower claim instead of appending a fault list to the original text.
- The default user-facing order is now primary result, scientific interpretation, evidence boundary, and next decision. Environments, parameters, file identities, and detailed lineage remain complete but expand only for reproduction or troubleshooting.

## Source assimilation and validation

- Every file in Life Sciences NGS Analysis 1.0.3 (81) and Life Science Research 1.0.3 (164) was inventoried and reviewed for implementation and license, covering 245 files. The release assimilates verifiable workflow contracts and interoperability patterns without copying the latter product's proprietary source.
- Six release capabilities were added. The registry contains 221 modules and 222 compatibility rows, with deterministic regression cases for local intake, completed-run recovery, evidence normalization, and interpretation correction.
- The complete local regression suite ran 1,349 tests, with 4 declared skips and all remaining tests passing; all 6 strict health checks passed. Remote continuous integration is bound to the final release commit.
