# 0.2.0-dev Journal Catalog Update

- Date: 2026-08-03
- Status: journal-catalog and documentation update
- Languages: [English](2026-08-03.md) · [中文](2026-08-03.zh-CN.md) · [Version index](README.md)

## Journal standards

- Expanded the active biomedical journal catalog from 54 to 100 profiles while preserving the immutable `2026.07.31` snapshot.
- Added the 2026 JCR metric frame based on 2025 data: JIF, ISSN/eISSN, every selected JCR category, edition, and category-specific quartile.
- Sorted the catalog and bilingual documentation by descending JIF. JIF remains excluded from project-to-journal fit scoring and acceptance-probability claims.
- Added explicit metric provenance levels. Direct Clarivate records remain preferred; the current public-data build uses an institutional JCR repost for covered titles and a declared specialist-index fallback for titles outside the truncated institutional export.
- Added source URL, retrieval date, source-artifact digest where available, and a deterministic digest for each admitted metric record.
- Publisher and journal pages remain the authority for title identity, publishing organization, scope, author instructions, article types, and manuscript rules.

## Validation

The catalog builder now requires exactly 100 active profiles, complete metric provenance for every profile, descending-JIF ordering, unique journal identifiers, bilingual table parity, and a digest-bound active index. Historical catalog versions remain loadable by explicit version.
