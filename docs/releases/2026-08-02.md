# 0.2.0-dev Release Notes

Date: 2026-08-02  
Status: development snapshot; release validation passed  
Languages: [English](2026-08-02.md) · [中文](2026-08-02.zh-CN.md) · [Version index](README.md)

## Highlights

- Established a 194-module scientific registry spanning evidence, data analysis, molecular and structural biology, clinical and experimental research, imaging and visualization, and publication and translation.
- Added parameterized execution and tiered acceptance for bulk chromatin accessibility, nascent transcription, RNA–protein binding, ribosome profiling, DNA methylation, R-loop mapping, RNA-modification enrichment, and three-dimensional genomics.
- Expanded single-cell batch, cross-species, multimodal, and reference integration together with spatial platform import, deconvolution, domain analysis, multislice alignment, and image-linked analysis.
- Added versioned scientific evidence maps, bilingual-report gates, unified figure specifications, a journal-standards catalog, and agent-facing credential configuration.
- Separated contract readiness, executor readiness, and public-data acceptance so configurable templates are not described as completed biological analyses.

## Evidence renewal policy

Changes to scientific implementation, parameter semantics, input handling, or output recognition require recomputation. Runtime or compatibility-policy changes require targeted retesting of the affected layer. Module descriptions or maturity changes require reviewed scope reissue. README, release-note, or unrelated module changes do not invalidate scientific results produced by the same executor.
