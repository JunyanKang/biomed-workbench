# 0.2.11 · 2026-09-03

[中文](2026-09-03-0.2.11.zh-CN.md) · [English](2026-09-03-0.2.11.md) · [版本索引](README.zh-CN.md)

本版本完善论文、报告和科研项目申请书的实际写作交付。写作不再从用户粘贴顺序、分析方法顺序或显著性大小直接组织，而是先结合经过核对的文献背景与项目证据，判断每项材料在科学论证中承担的作用，再完成语言修订和正式交付。

## 科学论证

- 按领域前提、知识缺口、主要发现、来源或背景、机制一致性、正交验证、阴性边界和综合判断组织证据，同时优先遵守真实的上下游依赖。
- 强制保留会限制中心结论的阴性结果和不一致证据，并要求提出至少一种生物学上合理的竞争性解释及其区分性验证。
- 论文和项目书分别使用适合目标文体的论证节奏；Nature、Cell、Science 与 JAMA、NEJM、The Lancet 的章节任务和读者需求由带日期的写作配置约束。

## 生命科学语言修订

- 新增对内部状态、软件工程比喻、流程管理和审计式措辞的专门识别，将其改写为具体的生物学对象、实验观察、推断、限制和可检验预测。
- 计算方法中必要的软件名、算法、参数、数据结构和定量结果不会被机械删除。
- 修订前后逐项核对数字、结果、公式、引用、专业术语、机制边界和有依据的不确定性；未通过内容保持检查的文本不能进入最终交付。

## HTML 写作报告

- 新增 `biomedical-writing-delivery` 模块。通过复核的文本写入内容寻址的版本目录，并同时生成 HTML 阅读页和 JSON 记录。
- HTML 页面提供目录、科学问题、证据顺序、原文与修订稿、待处理问题、项目证据链接、文献 DOI 和目标期刊依据。
- 写出后重新打开页面，检查导航、链接、内容与校验值；内存中的检查结果、路由或计划不再被视为写作交付。

## 验证

受控写作案例已通过真实文件写出、重新读取、页面结构、相对证据链接、DOI 链接和内容校验。完整本地套件运行 1,370 项，1,368 项通过，2 项按既定条件跳过；发布检查、6/6 严格健康检查及插件契约检查通过。正式发布仍以同一提交的远端持续集成全部成功为准。
