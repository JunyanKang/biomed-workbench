# Release Notes and Version Acceptance

[English](README.md) · [中文](README.zh-CN.md) · [Project home](../../README.en.md)

This directory preserves capability changes, observed execution acceptance, compatibility status, and release-quality results for each version or development snapshot. The root README describes the stable product architecture; datasets, tool versions, artifact counts, and test results that change over time are archived here.

## Versions

- [0.2.0-dev · 2026-08-03](2026-08-03.md): 100-journal catalog, tiered JIF/JCR provenance, category-specific quartiles, and bilingual JIF-sorted documentation.
- [0.2.0-dev · 2026-08-02](2026-08-02.md): bulk executors, single-cell and spatial expansion, scientific evidence maps, journal standards, and public-data acceptance.

Each note has a corresponding Chinese version and links to machine-verifiable evidence in `reports/`. Future versions receive new files; historical notes are not overwritten.
