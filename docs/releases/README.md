# Release Notes

This directory records capability changes, representative acceptance, compatibility updates, and known limitations for each release or development snapshot. The project home describes the stable way to use the workbench; specific datasets, software versions, and check results belong in the relevant release note.

- [0.2.0-dev · 2026-08-05](2026-08-05.md): improved review of negative results, scientific-decision records, runtime checks, and recovery of interrupted projects.
- [0.2.0-dev · 2026-08-04](2026-08-04.md): stronger output-content checks, evidence-scope review before formal delivery, recoverable evidence maps, and controlled-case records.
- [0.2.0-dev · 2026-08-03](2026-08-03.md): journal-targeting standards and bilingual reference maintenance.
- [0.2.0-dev · 2026-08-02](2026-08-02.md): bulk executors, single-cell and spatial expansion, scientific evidence maps, journal standards, and public-data acceptance.

Each note has a corresponding Chinese version and links to relevant validation results. Future versions receive new files; historical notes are not overwritten.
