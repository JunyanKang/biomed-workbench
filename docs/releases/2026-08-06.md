# 0.2.0-dev · 2026-08-06

[English](2026-08-06.md) · [中文](2026-08-06.zh-CN.md) · [Release index](README.md)

This development snapshot incorporates the scientific-gate, state-recovery, and method-revision corrections through the thirteenth code review.

## Scientific gates

- External-result contracts now bind each registered evaluator's callable identity, evaluator-contract version, and packaged source digest. Those fields enter the structured gate result and its receipt identity.
- `requires_review` and `not_evaluable` accept manual adjudication only; invented automatic-evaluator metadata cannot convert either status into acceptance.
- When a registered evaluator returns `failed`, the execution receipt, reloaded negative artifact, and exact automatic rejection are preserved. A major or fatal review must then choose exclusion, rerun, method change, or another non-retain action.
- A container or scientific-family admission failure rolls back content-addressed objects created by that ingest transaction and leaves no orphan payload.

## Research plans and state recovery

- Review-triggered rerun and method-switch actions now have a public preparation path. A registry-validated child plan freezes a node-level revision contract before the scientific decision; all outputs from the source execution must share its action, target, and request identity. Structured parameter changes execute through the same normalized request identity used by command modules, and untouched downstream work is rebound through an explicit output mapping.
- Method switching is separate from ordinary routing alternatives. Only a typed revision relation may define input, output, additional-artifact, and parameter mappings. The frozen replacement contract records whether claims are preserved, reset to target-specific evidence, or narrowed. FastQC and fastp are registered as decision-role alternatives with independent quality gates rather than metric-level equivalents.
- Parameter mappings now populate the target request before explicit overrides are applied, and the complete mapped target-parameter object is retained on the replacement node for exact resume.
- Project state advances to schema v2. A real v1 state produced by commit `10bafce`, containing three gate adjudications, is retained as a regression fixture. Migration verifies its digest and event chain, recovers added fields from the original receipts, and records the source digest and event count.
- Map-bound v1 states now use a non-overwriting migration command that verifies the immutable publication store and reports exact dependency-recovery blockers. Missing historical admission is recorded as unavailable rather than reconstructed and is bound to the exact migration source, verified map, map-coverage status, hypothesis, and expected outputs. Permanent legacy restrictions are reported separately from current delivery prerequisites.
- A real contract-1.1.0 state generated by the previous implementation is retained with its immutable map store. The new non-overwriting upgrade validates that prior state, its old migration and recovery digests, event chain, map files, plan-node contract, and true map coverage before writing a contract-1.2.0 successor with explicit upgrade provenance.
- Delivery prerequisites now use a three-state result. Without an exact delivery node they are `not-assessed`; `satisfied` or `blocked` is emitted only after the normal delivery validator has evaluated each requested node.
- Public journal guidance now focuses on project fit and manuscript requirements without exposing catalog size, metric rankings, or internal catalog-maintenance detail.

## Verification

- Lightweight counterexamples cover forged automatic adjudication, registered evaluator failure, exclusion after failure, object rollback, invalid or split-brain rerun targets, live-registry drift, typed method substitution with mapped values and no explicit override, public review-to-rerun reachability, map-bound v1 dependency recovery and republication, contract-1.1.0 upgrade, and immutable-map tampering.
- No large public-data analysis or new public-data download was performed.
