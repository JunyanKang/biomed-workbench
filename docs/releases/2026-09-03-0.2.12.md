# 0.2.12 · 2026-09-03

[English](2026-09-03-0.2.12.md) · [中文](2026-09-03-0.2.12.zh-CN.md) · [Release index](README.md)

This release closes the formal-delivery gap for ordinary project analysis reports. Manuscript and proposal writing already required a written and reopened HTML report, but a general analysis report could still end as Markdown or an in-memory result view. The two cases are now separated by an executable delivery contract.

## Analysis-Report Delivery

- The new `scientific-analysis-report-delivery` module writes scientifically reviewed observations, interpretations, experimental or statistical units, evidence boundaries, and next decisions into navigable HTML.
- A formal analysis report must declare HTML as its primary file and reopen it before delivery. Markdown may accompany the report but cannot satisfy delivery by itself.
- The page must link at least one real data file, figure, analysis script, or literature source. Local files are rehashed and a declared checksum mismatch stops delivery.
- Results that have not completed scientific review cannot enter a formal report. Concise conversational answers, backend JSON records, and tool-native FastQC or MultiQC quality reports retain their appropriate formats.

## Routing And Project Entry

- Common Chinese and English requests for an analysis report, complete project report, or scientific interpretation report now route to the HTML-delivery module.
- `project report` creates the formal HTML artifact from continuing-project result state. `project view` remains a quick inspection surface and is no longer treated as file delivery.
- When given a project root, the result view links registered payloads into the report and retains the actual experimental unit.

## Validation

Controlled tests cover ordinary report routing, HTML creation and reload, navigation and evidence links, rejection of Markdown-only delivery, rejection of unreviewed results, and preservation of tool-native QC routing. The complete local suite ran 1,376 tests: 1,374 passed and 2 were skipped under declared conditions. Release validation, isolated installation, plugin-contract checks, and the 6/6 strict health check passed. Formal publication still requires every remote continuous-integration job for the same commit to succeed.
