# Capability Maturity In Plain Language

Languages: [English](maturity.md) · [中文](maturity.zh-CN.md)

Every capability is shown with one outward-facing maturity level. The level applies to the exact method slice that was run; one validated backend never lends its status to another method in the same capability.

| Public level | What it means | What it does not mean |
| --- | --- | --- |
| `CONTRACT_ONLY` | Inputs, parameters, expected outputs and conditions of use are defined in a no-edit contract | The scientific program has run |
| `EXECUTED_FIXTURE` | The packaged implementation ran a controlled fixture and its declared outputs were reopened | The method is validated for every organism, platform, or study design |
| `PUBLIC_CASE_VALIDATED` | The same method slice also passed a representative public scientific case | The current user's data have been analysed or accepted |
| `CURRENT_PROJECT_VALIDATED` | One result from the current project completed execution, output reload, scientific review and formal inclusion | A broader claim than the observed project design supports |

The capability page may list validated method slices beneath the overall level. For example, a public LIANA–CellPhoneDB case establishes that slice only; CellChat, NicheNet, direct CellPhoneDB and SecAct retain their own status.

## Five steps in a project

Each analysis is also shown at one of five project steps: **planned**, **executed**, **outputs reopened**, **scientifically reviewed**, or **formally included**. These steps describe the current project rather than the general maturity of the method.

The default report leads with the biological observation, effect direction, interpretation boundary, and next decision. Software versions, parameters, environment identity, file digests and detailed lineage remain available in the reproducibility view without competing with the scientific result.

See [public-data cases](cases/README.md) for representative examples and [Project organisation and working modes](project-governance.md) for exploration, formalisation and submission use.
