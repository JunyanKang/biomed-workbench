# 使用 Biomed Workbench

语言：[中文](using-biomed-workbench.zh-CN.md) · [English](using-biomed-workbench.md)

## 从科学目标开始

调用 `biomed-workbench` 时，直接描述生物学问题、已有数据、实验单位和期望交付物即可。推荐使用自然语言；用户不需要知道模块名，也不需要手动串联多个 skill。

一个高质量请求通常包含：

- 科学问题或竞争性假设；
- 样本、队列、物种、实验体系、测定平台或分子对象；
- 可用文件和关键元数据；
- 对照、批次、供体、条件、时间点和参考版本；
- 期望得到的决策、图、结果段落、审稿回复、专利或展示材料；
- 物种、基因组版本、审查日期或报告标准等边界条件。

如果项目文件中能安全恢复必要信息，工作台应该直接检查文件。只有当关键信息无法推断且会实质改变分析时，才需要向用户确认。

## Agent 应该做什么

统一入口会选择单模块、串联、并联或混合工作流。随后应当完成：

1. 验证项目上下文和输入契约；
2. 写明工作假设、实验单位和决策标准；
3. 选择科学模块并标注 artifact 依赖；
4. 在执行前检查工具兼容性和证据可用性；
5. 通过模块声明的参数界面绑定真实项目数据并执行已封装流程；
6. 重新读取输出并按模块质量门控审查；
7. 当结果反驳假设或质量失败时修正计划；
8. 组装可解释 artifact 和 claim-evidence 证据链；
9. 从统计、生物学和发表角度复核；
10. 交付结果，并保留失败项、限制和未解决问题。

公开单模块入口会在项目目录内原子保存可重放状态，并分别报告计算是否完成与科学评审进行到哪一步。再次使用同一状态时，未完成计划必须先走结果回收、评审、决策或继续执行；已完成计划可以在原事件账本上追加新分析，不会重建或覆盖历史。外部封装流程完成后，只有与原交接单完全一致的模块、版本、兼容组合、运行版本、退出状态、产物身份和内容校验全部通过，结果才会进入待评审状态。

如果评审要求重跑或更换方法，Agent 会先建立新的计划版本，再登记该项科学决策。替代分析必须通过实时方法注册表核对，固定具体参数变化和科学理由，并在执行前重新完成分析准入。同一次原分析产生的全部输出共用同一个替代方案，不能把一张表和对应图分别送入相互冲突的重跑。只有来源方法明确登记了可执行替换关系，并给出输入、输出和参数映射时，才能原位更换方法；仅列为相关备选的方法不能直接替换。

已经发布过证据地图的旧项目，只有在旧地图文件全部校验通过后才会迁移到新的状态文件。迁移结果会列出缺少的评审、决策、准入和未解决门禁。旧格式无法证明事前分析批准时，新状态只记录这一历史缺口，不补造批准。逐份完成产物评审和决策后，可以发布明确延续旧版本的项目快照；这类历史恢复不能授权科研交付，也不会提高证据强度。

分析完成后，每个 data、table、model、Figure 和 panel 都需要进入科学证据地图，绑定前置结论、生产脚本、renderer、最终文件、caption、叙述来源、DOI、路径与校验值。中英文解读报告从通过校验的同一版本地图生成。

## 项目检查点

复杂项目不应把第一次运行成功当作完成。工作台应维护明确检查点：

- **输入接收：** 数据清单、样本设计、元数据完整性、格式和参考兼容性。
- **分析准备：** 可执行计划、模块契约、混杂因素、统计单位和预期 artifact。
- **结果有效性：** 技术 QC、生物学合理性、敏感性分析、阴性结果和竞争解释。
- **科学解释：** 每个关键主张的支持、反驳和因果边界。
- **交付一致性：** 图、方法、表格、引用、审查意见和可重复性记录相互一致。

## 示例请求

> 为这个靶点建立 PubMed、UniProt、ClinVar、临床试验、PDB 和 AlphaFold DB 的证据地图，统一冲突 identifier，并区分已证实发现和假设。

> 分析这个 bulk RNA-seq 项目，使用供体感知统计、通路和网络解释、敏感性检查和 figure-to-claim 计划；如果主比较不成立，修正假设。

> 为这些 H5AD 文件设计并审查单细胞分析流程，保留未知细胞状态，比较整合和注释证据，并把验证后的结论整理成稿件结果段落。

> 审查这套分子设计方案，从序列和结构质量到 docking pose 与实验验证计划；不要把预测置信度当作结合证据。

## 交付物

根据任务不同，输出可以包括数据清单、工作流计划、分析 artifact、质量报告、证据表、图、方法、稿件、审稿意见、response matrix、专利披露或展示方案。每个交付物都应说明哪些内容已执行、哪些内容只是推断、哪些检查失败、哪些问题仍未解决。
