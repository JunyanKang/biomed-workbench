# NCBI J01673.1 Assembly Alignment Case

The acceptance case aligns the public NCBI Nucleotide record `J01673.1` against
the same declared sequence with minimap2 `asm5`. It verifies FASTA identity,
tool version capture, reloadable PAF coordinates, and query-target accounting.

It is deliberately a method-level case. The observed alignment does not claim
variants, haplotypes, synteny, structural variation, orthology, or functional
conservation.
