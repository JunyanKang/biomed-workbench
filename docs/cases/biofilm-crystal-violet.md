# Crystal-Violet Biofilm Summary Case

This deterministic case retains two blank wells, two control measurements, and
two treated measurements. It computes blank-corrected group summaries and
control-normalized effects while preserving all input values and precision
flags.

The result does not assign a p-value to one value per group or establish
treatment efficacy. A comparative conclusion needs independently cultured
biological replicates, plate-layout review, and a predeclared model.
