# 能力成熟度与证据等级

模块成熟度与某个项目的证据强度是两回事。`validated` 表示模块包、执行契约、兼容性组合、回归案例和代表性执行证据通过；它不表示对所有物种、实验、化学体系、队列和数据都自动有效。

| 证据层级 | 已证明 | 仍未证明 |
| --- | --- | --- |
| 契约 | 清单、格式、产物、质量门控和入口有效 | 真实运行和科学结果 |
| 兼容性 | 指定工具、依赖、平台和格式组合通过 | 其他版本、平台和设计 |
| 公开数据验收 | 当前工具或稳定公共数据通过预定门控 | 对其他数据和参数的推广 |
| 项目验证 | 用户真实输入运行、重读并通过项目门控 | 超出实验单位和观察证据的主张 |

`experimental` 表示模块已有可用契约与无需改源码的模板，但仍需更多后端、公共数据或真实项目验收。`agent_generated` 描述由 Agent 绑定参数并调用封装流程的执行方式，不是成熟度；计划本身不能进入证据地图。

最终结论以项目验证为准。未运行、失败或阻断的门控必须保留，进程退出为零也不能代替科学审查。
