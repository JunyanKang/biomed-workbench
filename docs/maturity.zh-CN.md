# 怎样理解能力成熟度

语言：[中文](maturity.zh-CN.md) · [English](maturity.md)

每项能力只使用一套对外成熟度。等级对应真实运行过的具体方法，不能把同一模块中某个方法的验收结果借给其他方法。

| 对外等级 | 表示已经做到 | 不表示 |
| --- | --- | --- |
| `CONTRACT_ONLY` | 输入、参数、预期输出和适用条件已经形成无需改源码的执行约定 | 科学程序已经运行 |
| `EXECUTED_FIXTURE` | 已用受控测试数据运行登记实现，并重新打开规定输出 | 适用于所有物种、平台或实验设计 |
| `PUBLIC_CASE_VALIDATED` | 同一个方法还通过了代表性公共科学案例 | 当前用户的数据已经完成分析或被项目采用 |
| `CURRENT_PROJECT_VALIDATED` | 当前项目中的一个具体结果已完成运行、结果重读、科学评审和正式纳入 | 可以超出本项目设计扩大解释 |

能力页面可以在总体等级下面列出已经通过公共案例的方法。例如，LIANA–CellPhoneDB 的公共案例只说明这一方法已经验收，不能同时证明 CellChat、NicheNet、直接 CellPhoneDB 或 SecAct 已通过同样验收。

## 当前项目的五个步骤

每项分析同时显示五种直观进度之一：**已规划、已执行、已重新打开结果、已完成科学评审、已正式纳入**。这些步骤描述当前项目，不等同于方法本身的一般成熟度。

默认报告优先呈现生物学观察、效应方向、解释边界和下一步决定。软件版本、参数、运行环境、文件校验和及详细来源关系保留在可复现性视图中，不与科学结果争夺阅读空间。

代表性案例见[公共数据案例](cases/README.zh-CN.md)，探索、定稿和投稿阶段的使用方式见[项目组织与工作模式](project-governance.zh-CN.md)。
