# Biomed Workbench Notice

Biomed Workbench is an independent Codex plugin that organizes biomedical research capabilities into one user-facing skill and a local tool catalog.

## Independent Implementation

The workbench is a product-owned Codex plugin organized around Biomed Workbench module contracts, compatibility policies, and scientific quality gates. Public distribution contains the plugin source, documentation, module manifests, templates, tests, and release evidence needed to install and use the product.

## Redistribution Boundary

This repository does not vendor external source trees, local workspaces, credentials, temporary development artifacts, or third-party scientific datasets. Operational code does not import or dispatch into private development repositories.

Users are responsible for complying with the terms of external databases, datasets, and APIs they use through this workbench.
